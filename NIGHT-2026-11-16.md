# robot-play: overnight plan (16 to 17 Nov 2026)

## The question

Can an LLM that only orchestrates robot skills get **faster, cheaper and steadier** at long-horizon manipulation by playing the same environment over many episodes, with no training? And does that experience help it **recover from disturbances**?

The bold headline we are testing is this: *a cheap model (Haiku 5.5 / GPT-6 Luna) with N episodes of experience matches a frontier model (Fable 5.2 / GPT-6 Astra) on its first try, at a fraction of the cost.*

## How this differs from the closest prior work

| Work | Tool level | Learning over episodes | Disturbances | Hidden env quirks |
|---|---|---|---|---|
| RoboARCade (2611.08209) | Pose tools (set_pose, gripper) | 1 demo in context, 2 prompt-revision rounds | none | none |
| WICL / RoboScript (2611.12885) | Code + task memory from rehearsal | Rehearsal from 1 demo; no per-episode curve | none (scene randomisation only) | none |
| GPT-Policy (2609.19138) | IK-backed pose tools, real robot | 3 trials per condition | none | none |
| Voyager / ExpeL | Minecraft / text envs | Yes | No | No |
| Inner Monologue / LangPert / ROBOREPAIR | Skills | No | Yes | No |
| **robot-play** | **Skill tools (IK + motion planning) and pose tools, ablated** | **Curves over 50-100 episodes: success, sim time, tool calls, tokens, $, variance** | **Injected mid-episode, recovery scored** | **Yes: per-environment hidden quirks that only experience reveals** |

## The design

1. **Robots.** MuJoCo Menagerie models (Apache-2.0): Franka Panda and RobotStudio SO-101. Each one gets randomised variations: object pose, size, mass and friction.
2. **Skills.** These are LLM tools built on damped least-squares IK and joint-space motion planning, with collision checking (an RRT-Connect fallback). The tool set is `observe`, `pick(object, grasp_height?, approach?)`, `place(target/xy, release_height?)`, `push(object, direction, distance)`, `move_to(xyz)`, `open/close_gripper`, `home`. Every tool returns *honest* physical feedback: contact, whether something is held, the final pose, and IK or plan failures.
3. **Tasks.** These are long-horizon: stack-3, sort-by-colour into bins, clear the table, build a tower in a given order, and pass an item through a narrow gap. Each environment has **hidden quirks** the agent is not told about, for example:
   - an object that slips unless grasped low;
   - a bin with a lip that needs a higher release;
   - a perception bias on one object;
   - an out-of-reach zone that requires a push first.

   These are what in-context learning can discover.
4. **Memory conditions, all without training:**
   - **none**;
   - **lessons notebook**: the agent writes lessons after each episode, ExpeL-style;
   - **best-trajectory replay**: the last successful episode goes in context, as in RoboARCade;
   - **macros**: the agent saves parameterised tool sequences and calls them later, Voyager-style.
5. **Disturbances:**
   - an object is moved mid-task;
   - a grasp slips (forced drop);
   - a tool fails (IK or plan timeout);
   - the instruction changes mid-episode;
   - a new obstacle appears.

   We score recovery and compare experienced agents with fresh ones.
6. **Metrics per episode:**
   - success from a task predicate checked by the simulator, never from the LLM's own claim;
   - false-success claims;
   - sim time and tool calls;
   - input and output tokens and $;
   - recovery success after a disturbance.

   We report learning curves with bootstrap confidence intervals over seeds.
7. **Models:**
   - Anthropic: Haiku 5.5, Sonnet 5.5, Fable 5.2.
   - OpenAI: GPT-6 Luna, 6.1 Sol, 6 Astra.

   Judges (Fable, Codex 6.1 Terra) are kept separate from the orchestrators where possible.
8. **Budget.** Anthropic stops hard at $90 and OpenAI at $45, enforced by the spend meter in the harness. Cheap models run first, and the frontier models only run once the harness has proved itself.

## Order of work tonight

1. Sim core: scenes, the IK, planning and skill layer, and scripted-oracle tests showing that each skill works (pick, place and stack succeed ≥ 95% with scripted calls).
2. Task suite with hidden quirks and predicates. A scripted oracle that knows the quirks solves each task; a naive script that doesn't know them fails some. This proves the quirks matter.
3. LLM agent loop for Anthropic and OpenAI, with the spend meter, episode logging, memory conditions and disturbance injection.
4. Smoke runs on Haiku and Luna (a few dollars), then fixes.
5. The main experiment: learning curves for the cheap models, memory on vs off, across tasks. Then the disturbance experiment. Then a small frontier reference.
6. Analysis: plots, a results table, and a README with related work. Push to github.com/TarunTomar122/robot-play.

## Council
